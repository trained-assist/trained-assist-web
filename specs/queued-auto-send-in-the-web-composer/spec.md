# Queued auto-send in the web composer

## Requirements
Как пользователь веб-чата, пока агент ещё выполняет предыдущую задачу, я хочу сразу набрать (или продиктовать) следующий ответ, и хочу, чтобы он ушёл сам, как только текущий прогон завершится — без «подготовь черновик и не забудь нажать Отправить потом». Сейчас кнопка «Отправить» заблокирована на время выполнения (notice «Можно подготовить следующий ответ. Отправка станет доступна после завершения»), и набранное просто лежит черновиком. Решение: composer становится настоящей очередью из одной позиции — пока сессия running, любой непустой текст/вложение в привязанном к этой сессии composer'е помечается как «отправится автоматически»; по завершении прогона он уходит через тот же sendMessage. Область — только reply-режим той же сессии; новую сессию и чужие сессии авто-отправка не трогает.

## Acceptance criteria (EARS)
- КОГДА сессия в статусе running И пользователь вводит непустой текст в composer этой сессии, система ДОЛЖНА показать notice «Отправится автоматически, когда агент закончит» и кнопку отмены авто-отправки, оставляя кнопку «Отправить» заблокированной
- КОГДА пользователь нажимает «Отменить автоотправку», система ДОЛЖНА снять пометку и вернуть прежний notice «Можно подготовить следующий ответ…», сохранив текст как обычный черновик
- КОГДА прогон сессии завершается (SSE done или polling видит статус != running), система ДОЛЖНА автоматически отправить подготовленный ответ через sendMessage ровно один раз при условии, что composer привязан к той же reply-сессии
- КОГДА пользователь печатает в момент завершения прогона, система ДОЛЖНА дождаться паузы в наборе (~1.2 c без ввода) перед авто-отправкой, чтобы не отправить недописанное
- КОГДА диктовка расшифрована, пока агент занят, система ДОЛЖНА добавить текст в черновик И пометить его к авто-отправке (в покое диктовка по-прежнему требует ручного Send)
- КОГДА авто-отправка не подтверждена сервером или пользователь нажал Стоп/Дополнить, система ДОЛЖНА снять пометку и сохранить черновик, не повторяя отправку
- КОГДА выполняется commit, система ДОЛЖНА проходить syntax check и Playwright UX-тест, включая новый сценарий очереди

## Out of scope
- Авто-отправка для режима «Новая сессия»
- Авто-отправка текста, набранного в composer другой (не связанной) сессии
- Очередь из более чем одного сообщения
- Авто-отправка при простое (ничего не выполняется)
- Изменения на стороне агента/worker — только клиентский UI
